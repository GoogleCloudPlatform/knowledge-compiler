# Entities

OKF v0.3 subdirectory index for `wiki/entities/` (see [Master Index](../../index.md) and [Wiki Index](../index.md)).

- [BigQuery](BigQuery.md): Google Cloud's fully managed, serverless data platform for SQL analytics, with partitioned and clustered tables, streaming ingestion, and queryable job metadata.
- [Cloud PubSub](Cloud%20PubSub.md): Pub/Sub, Google Cloud's asynchronous messaging service that decouples event producers from consumers through topics and push, pull, or export subscriptions.
- [Cloud Run](Cloud%20Run.md): Google Cloud's managed platform for running containers as request-driven services and run-to-completion jobs without managing servers or clusters.
- [Cloud SQL for PostgreSQL](Cloud%20SQL%20for%20PostgreSQL.md): Google Cloud's fully managed PostgreSQL service, used in this vault as the transactional store behind an idempotent event consumer.
- [Google Kubernetes Engine](Google%20Kubernetes%20Engine.md): Google Cloud's managed Kubernetes service, offered in Autopilot and Standard modes, for workloads that need the full Kubernetes API.
